# 跑步姿态AI分析系统

一个基于多模态大语言模型的跑步姿态分析工具，专为小学生跑步动作评估设计。通过上传8-10秒的跑步视频，系统会自动提取关键帧并生成详细的专业评估报告。

## 特性

- 视频帧提取 - 浏览器端自动半随机提取4帧关键画面，无需服务器处理
- 多模型支持 - 兼容 DeepSeek、Gemini、GPT 等 OpenAI 格式的视觉模型
- 专业评分 - 基于小学生跑步标准的100分制评分体系
- 角度测量 - 智能识别摆臂角度并评估对称性
- 训练建议 - 提供可操作的改进方案和训练计划
- 现代UI - 深蓝色科技风格，荧光青色点缀，支持自定义滚动条

## 评分标准

系统采用四维度评分体系（总分100分）：

### 摆臂技术（30分）
- 肘关节角度标准：85-95度
- 摆臂方向：前后直线摆动
- 左右对称性：角度差≤5度
- 提供每帧的具体角度数据

### 躯干姿态（25分）
- 躯干稳定性：轻微前倾5-10度，无晃动
- 头部位置：正直，平视前方
- 核心控制：核心收紧，腰背直线

### 下肢动作（25分）
- 步幅与步频：步幅为身高0.8-1.0倍，步频160-180步/分
- 着地方式：前脚掌先着地
- 膝关节缓冲：自然弯曲，缓冲流畅

### 整体协调性（20分）
- 上下肢配合：对侧摆动协调流畅
- 节奏感：节奏稳定，呼吸均匀

## 快速开始

### 1. 准备工作

确保你有以下资源：
- 支持视觉输入的多模态 LLM API
- API Key（确保还有余额）
- 8-10秒的跑步视频（MP4/MOV/AVI格式，确保人物全身清晰可见）

### 2. 使用方式

#### 方式A：本地使用（不推荐）
直接用浏览器打开 index.html 文件（会导致localStorage无法使用）

#### 方式B：本地HTTP服务器
```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve

# 访问 http://localhost:8000
```

#### 方式C：GitHub Pages
直接访问：https://ssssshuan.github.io/run-analysis-ai/


### 3. 使用步骤

1. **配置API**
   - 填写API地址
   - 填写API Key
   - 填写模型名称

2. **上传视频**
   - 点击上传区域或拖拽视频文件
   - 等待系统自动提取4帧关键画面

3. **开始分析**
   - 点击"开始分析"按钮
   - 等待AI生成报告（约20-60秒，视模型而定）
   - 可随时点击"终止分析"取消

4. **查看报告**
   - 浏览各维度评分和详细评价
   - 查看摆臂角度数据
   - 阅读优点、改进建议和训练计划
   - 点击"导出报告"下载Markdown格式

## 技术实现

- **前端框架**: 原生 HTML5 + JavaScript
- **视频处理**: Canvas API 进行帧提取
- **图像编码**: Base64 编码传输
- **API格式**: OpenAI-compatible Messages API
- **样式**: CSS3 渐变、阴影、动画
- **响应式**: 左右分栏布局，100vh无滚动

### 关键技术点

1. **浏览器端帧提取**
   - 使用 video 元素加载视频
   - 通过 canvas.drawImage() 截取画面
   - Base64编码后发送给API

2. **多模型兼容**
   - 统一使用 OpenAI Messages 格式
   - 支持 content 和 reasoning_content 字段
   - 自动补全API路径（/v1/chat/completions）

3. **报告解析**
   - 支持 [标签] 和 ## 标题 两种格式
   - 正则提取评分、角度、列表项
   - 容错性强，支持多种LLM输出风格

## 常见问题

### 1. API返回HTML而不是JSON
**原因**: API地址不正确，可能缺少 /v1 路径  
**解决**: 系统会自动补全，也可手动添加完整路径

### 2. 上传按钮点击无反应
**原因**: JavaScript语法错误导致页面初始化失败  
**解决**: 打开F12查看Console错误信息

### 3. localStorage无法使用
**原因**: file:// 协议下localStorage被禁用  
**解决**: 使用 http:// 或 https:// 访问（本地服务器或GitHub Pages）
